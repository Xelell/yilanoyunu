# Yılan Oyunu 🐍

Python ve Pygame kullanılarak yapılmış basit bir yılan oyunu.

## Gereksinimler
- Python 3.x
- Pygame

## Kurulum
```bash
pip install -r requirements.txt
```

## Oyunu Çalıştırma
```bash
python main.py
```

## Kontroller
- **⬆️ Yukarı Ok** - Yılanı yukarı hareket ettir
- **⬇️ Aşağı Ok** - Yılanı aşağı hareket ettir
- **⬅️ Sol Ok** - Yılanı sola hareket ettir
- **➡️ Sağ Ok** - Yılanı sağa hareket ettir

## Oyun Kuralları
- 🔴 Kırmızı kareleri (yem) ye
- Her yem = +10 puan
- 🟢 Yeşil kare = Yılanın gövdesi
- ⚠️ Duvara veya kendi kendine çarpma = Oyun Bitti!

## Oyun Özellikleri
- Grid tabanlı hareket sistemi
- Skor takibi
- Kolay kontroller
- Minimalist tasarım
